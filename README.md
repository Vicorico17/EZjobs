# EZJobs

A responsive job discovery and quick-apply prototype built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Features

- Search by role, skill, company, or location
- Filter by discipline and remote availability
- Save jobs locally
- Browse job details and fit indicators
- Complete a two-step quick application flow
- Responsive desktop and mobile layouts
